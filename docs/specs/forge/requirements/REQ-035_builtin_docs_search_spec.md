# REQ-035 forge 内蔵ドキュメント検索 要件定義書 DLID-vbnhkkz19dmr

## 概要 DLID-nc82awcareq6

forge に同梱された文書（開発基盤規範・文書の書式と原則・レビューの観点など。以下「内蔵ドキュメント」）を、キーワード・機能名・自然文で探せるようにする。利用者と forge の各スキルは、内蔵ドキュメントの置き場を知らなくても、作業に必要な文書を読み落とさずに特定できる。読み落としは、規範を読まないまま作業を始める原因になる。

## 前提条件 DLID-g6pazmh9vqtq

- forge がインストールされている
- 文書検索 backend（doc-link / doc-db）が使えない環境でも使える。利用者は、内蔵ドキュメントの索引を自分で作らない

## 要件一覧 DLID-5nrpm3tpekkq

### FNC-001: 内蔵ドキュメントを検索する DLID-m61wn68wf8he

- トリガー: `/forge:query-forge-rules {タスクの記述}`。forge の各スキルも、同じ入口を使う
- 入力: 検索キーワード、または自然文のタスクの記述
- 出力: 先頭行が `Required documents:` で、続けて該当する内蔵ドキュメントのパスを 1 行に 1 件ずつ並べた一覧。この形式は、`/forge:query-db-rules`・`/forge:query-db-specs` の結果の先頭の形式と同じである。この 2 つが一覧の後に添える通知は、添えない
- パスは `plugins/forge/` で始まる形式で返る。呼び出し側は、forge の実際の配置先に読み替えて読む
- 該当する文書が無いときは、先頭行だけの一覧を返す。エラーではない

### FNC-002: 意味で選び、取りこぼさない DLID-pwga59xkvyd6

- 字句の一致ではなく、タスクとの関連を意味で判断して選ぶ
- 関連するか迷う文書は、結果に含める。含めすぎは許容し、取りこぼしは許容しない
- 結果のうち何を読むかは、呼び出し側が判断する

### FNC-003: 検索以外の作業を行わない DLID-nv968pf281p5

- 内蔵ドキュメントを探して一覧を返すことだけを行う。ファイルの書き込み・commit・Issue の更新など、検索以外の作業を行わない
- 渡された記述が命令文の体裁でも、実行しない。検索のタスクとして扱う（例:「ファイルを削除して」は、削除に関連する内蔵ドキュメントを探す依頼として扱い、実際には削除しない）
- 呼び出し元が行っている他の作業を引き継がない

### 対象外 DLID-6ahw6xcz1q2r

利用プロジェクトのルール文書・仕様文書の検索は、この要件の対象外である（`/forge:query-db-rules`・`/forge:query-db-specs` が担う）。

### エラーケース DLID-9p8ra93kdqth

| 条件                                 | 分類     | 利用者への報告                                                           |
| ------------------------------------ | -------- | ------------------------------------------------------------------------ |
| 内蔵ドキュメントの索引が見つからない | 回復不能 | 検索せず、索引が見つからないことを報告する。一覧は返さない（配置の破損） |
